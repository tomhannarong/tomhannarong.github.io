# tomhannarong.github.io

Project portal for [https://tomhannarong.github.io/](https://tomhannarong.github.io/).

The site is the front door for live GitHub Pages projects, profile links, demos, tools, and public repositories.

## Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- GitHub Actions for GitHub Pages deploy

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Deploy

GitHub Actions builds the Vite app and deploys the `dist` folder to GitHub Pages whenever `main` is updated.

Repository settings should use:

- Settings -> Pages -> Build and deployment -> Source: GitHub Actions
